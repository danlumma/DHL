# Personal Knowledge Hub (PKnH)

This repository is a starter system for building and maintaining a **personal knowledge hub** using plain Markdown files.

## What this gives you

- A clean folder structure for notes and knowledge.
- A dashboard page to quickly navigate your hub.
- Reusable templates for daily notes, projects, and evergreen notes.
- A simple weekly maintenance workflow.

## Structure

```text
hub/
  dashboard.md
  inbox.md
  areas/
  projects/
  resources/
  archive/
  templates/
```

## Quick start

1. Capture quick ideas in `hub/inbox.md`.
2. For active initiatives, create notes in `hub/projects/`.
3. For long-term responsibilities, use `hub/areas/`.
4. For reference material, use `hub/resources/`.
5. Move outdated notes into `hub/archive/`.

## Suggested weekly ritual (15-30 minutes)

- Process `inbox.md` and move each item to the right folder.
- Update project next actions.
- Add links between related notes.
- Archive stale items.

## Optional enhancements

- Add backlinks/graph view using Obsidian, Logseq, or VS Code extensions.
- Add a simple search script or static site generator later.
